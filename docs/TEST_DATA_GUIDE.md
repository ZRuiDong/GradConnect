## 建议测试顺序

1. 管理员查看学生信息，组合班级/党支部/政治面貌/当前职务等条件；拖动列宽，悬停查看长姓名，进入详情查看完整资料和履职历史。
2. 在各模块分别设置每页 7、20、50、100 条，输入页码跳转；检查多选、关键词、日期范围、排序条件保持，修改条数后回到第一页。每个模块分别记住当前会话的条数设置。
3. 用两名学生互相复制咨询、请假、实习、租房及附件地址；他人私有数据应拒绝访问。发布内容可查，草稿、撤下通知/指南、草稿制度附件和删除视频不可查。
4. 用 `qa000001` 测试待审撤销、驳回重提、管理员审批与销假；已审核申请不能再次按待审逻辑处理。租房选择“其他”或有校内宿舍时检查条件必填，驳回时必须写原因。
5. 管理员按跨年月份与打卡/请假/总天数范围查询，点击六列表头排序；导出请假时应包含筛选结果的全部分页。
6. 两名管理员同时打开同一学生编辑页，先后保存；后保存的旧页面应提示冲突。先上传更新预览再修改目标资料，旧预览确认也应被拒绝。
7. 删除 `qa001500` 应彻底删除；删除 `qa000001` 应归档停用并保留历史，可按归档条件找到。恢复后仍需单独启用登录。

## 导入和附件样本

文件包为 `media/qa_seed/v1/fixture-bundle.zip`。可在通知汇总搜索“测试”，找到附件为 ZIP 的已发布测试通知下载；也可在本地打开该文件。

| 文件 | 测试方式 |
| --- | --- |
| `valid/new-students.csv` | 学生信息“新增账号”模式，新增 50 个 `qa_new` 账号 |
| `valid/update-politics.csv` | “更新已有资料”模式，只更新政治面貌，其余字段应保留 |
| `valid/monthly-attendance.csv` | 月度打卡导入；同人同月重导应更新，不重复创建 |
| `graduate-list.xlsx` | 毕业名单导入；包含在校和已毕业学生，验证幂等处理 |
| `tenure-list.xlsx` | 履职导入；包含空结束日期、多当前职务和未来任职 |
| `invalid/*.csv` | 错误姓名、负数、小数、超月长、非法月份、同人同月重复，应整批拒绝 |
| `invalid/disguised.pdf`、`invalid/unsupported.svg` | 伪装文件和不支持的格式，应拒绝附件上传 |

其他真实 PDF、Word、Excel、图片、文本、CSV 和视频样本位于同目录，并已挂接在测试业务中。Excel 样本的任职日期以生成基准日期设计；修改学生姓名后需同步修改导入名单。测试样本不涉及真实身份证或个人联系方式。

## 重复生成、统计和清理

命令仅允许在 `DJANGO_DEBUG=1` 的开发环境使用：

```sh
.venv/bin/python manage.py seed_test_data --check
.venv/bin/python manage.py seed_test_data
.venv/bin/python scripts/check_qa_data.py
.venv/bin/python manage.py test portal
```

重复生成会检测完成标记并直接返回，不覆盖手工修改、密码或演练结果。生成/清理前自动备份；命名空间冲突时拒绝覆盖原账号。需要重建时，先核对并执行以下清理，再重新生成：

```sh
.venv/bin/python manage.py seed_test_data --clear
.venv/bin/python manage.py seed_test_data --students 1500
```

旧版测试数据中预设的特殊符号、公式前缀、超长和空姓名已改为常规中文姓名；对应请假、实习、租房和打卡中的旧姓名同步修复，人工编辑过的姓名保留。这些极端输入继续由隔离自动测试覆盖，常用测试库不再生成这些姓名。其他本地副本可执行 `.venv/bin/python manage.py seed_test_data --repair-names`：自动备份后仅处理明确识别的旧测试姓名，可重复运行，无需清空重建测试库。涉及学生的旧编辑页/导入预览按原冲突检测规则重新核对。

清理按测试分组和归属识别，不仅凭 `qa` 或“【测试】”前缀删除。通过页面额外导入的 `qa_new` 账号不自动属于初始测试分组，不会擅自清除；新增的非测试内容或外部关联引用测试账号时会阻止清理，需先人工核对。共享附件仍被其他内容引用时保留文件。清理后的测试账号会重建为初始状态。

本套数据用于功能和分页演练，不代表生产并发压测。数量记录见 `TEST_DATA_COUNTS.json`，原记录保留核对见 `QA_DATA_PRESERVATION_RESULTS.json`，最新页面检查见 `UI_PAGINATION_HTTP_RESULTS.json`。
